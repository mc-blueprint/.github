# mc-blueprint

曖昧な依頼（「中世風の巨大な城を作って」など）から、Minecraft Java Edition の建築・地形を schematic として生成するツール群です。AI コーディングエージェントからの利用を前提にしています。

| リポジトリ | 内容 |
|---|---|
| [mc-blueprint](https://github.com/mc-blueprint/mc-blueprint) | 生成ツール本体（CLI・Python API・エージェント用 Skill） |
| [mc-blueprint-viewer](https://github.com/mc-blueprint/mc-blueprint-viewer) | 3D 表示 |
| [mc-blueprint-blockdata](https://github.com/mc-blueprint/mc-blueprint-blockdata) | 版ごとのブロックの状態・色・材質 |
| [mc-blueprint-patterns](https://github.com/mc-blueprint/mc-blueprint-patterns) | 様式・部品・敷地のパターン |
| [mc-blueprint-color-stats](https://github.com/mc-blueprint/mc-blueprint-color-stats) | 実在の建築・地形の配色統計 |

非公式のプロジェクトで、Mojang Studios・Microsoft とは関係ありません。Minecraft の jar・テクスチャは配布しません。
